# Bem-vindo a The Crazy Egypt!
Joguinho feito em Pyzero 

Objetivo: Colete pelo menos 6 de cada item: Sol, Chave e Tábua, enquanto desvia de inimigos como morcegos e múmias.

Controles: Seta para a esquerda ($\leftarrow$) move para a esquerda, Seta para a direita ($\rightarrow$) move para a direita, Espaço pula.
Você vence ao coletar todos os 18 itens.
Divirta-se!

-------------------------------------------------------------------

#Welcome to The Crazy Egypt!
A small game made using Pyzero

Goal: Collect at least 6 of each item: Sun, Key, and Plank, while avoiding enemies like bats and mummies.

Controls: Left arrow ($\leftarrow$) to move left, Right arrow ($\rightarrow$) to move right, and Space to jump.
You win once you collect all 18 items.
Enjoy!
